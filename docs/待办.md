## P3.5 — Agent 群组协同能力增强

### 13. Agent 协作意识 ⚠️ 当前仅被动响应消息

- [ ] 成员画像感知 — Agent 加入群组时自动获取其他成员的 CHARACTER/JOB 摘要，了解各自擅长领域
- [ ] 协作上下文注入 — 将群组目标（TASK.md）、当前计划（PLAN.md）、进度（PROGRESS.md）作为 system context 注入每个成员
- [ ] 角色自适应 — Agent 根据群组任务自动调整行为模式（如代码任务中后端 Agent 主动承担 API 部分）
- [ ] 能力互补识别 — Agent 分析任务后主动识别需要哪些角色协助，而非等用户指派

### 14. 主动协作行为 ⚠️ 当前只能被 @mention 唤起

- [ ] 主动求助 — Agent 遇到超出自身 JOB 范围的任务时，主动在 main 频道请求对应角色的成员协助
- [ ] 主动贡献 — Agent 读到其他成员的讨论时，若自身 JOB 涉及该话题，可主动发言提供专业意见
- [ ] 进度同步 — Agent 完成阶段性工作后主动向群组汇报进度，更新 PROGRESS.md
- [ ] 阻塞上报 — Agent 卡住时主动告知群组并说明卡住原因，而非静默等待

### 15. 任务分解与分派 ⚠️ 当前无结构化任务流转

- [ ] 任务拆解 — 群主或管家将大任务拆解为子任务，分配给具备对应能力的成员
- [ ] 子任务追踪 — 每个子任务有独立状态（pending/in-progress/completed），关联到负责的 Agent
- [ ] 依赖管理 — 子任务间可声明依赖关系，上游完成后自动通知下游开始
- [ ] 交付物验收 — 子任务完成时由群主或关联 Agent 验收，不合格则打回重做

### 16. 冲突解决与共识机制 ⚠️ 当前无冲突处理

- [ ] 意见分歧检测 — 识别群组讨论中 Agent 之间的观点冲突
- [ ] 投票表决 — 对争议方案发起投票，按多数意见推进
- [ ] 仲裁机制 — 群主或用户作为最终仲裁者，在无法达成共识时拍板
- [ ] 方案对比 — 将多个候选方案结构化列出，方便用户/群主决策

### 17. 知识共享与经验传递 ⚠️ 当前各 Agent 知识完全隔离

- [ ] 群组经验沉淀 — 协作过程中的关键决策和教训写入群组级 EXPERIENCE.md
- [ ] 跨 Agent 知识传递 — Agent A 解决的问题经验可被同群组的 Agent B 参考
- [ ] 协作模式总结 — 群组协作结束后自动总结哪些协作模式有效/无效，供后续群组参考
- [ ] 最佳实践库 — 高频协作场景沉淀为可复用的协作模板（如"前后端联调"、"代码审查"等）

## P4 — 子智能体优化

### 18. 子智能体生命周期管理 ⚠️ 当前仅基础 spawn/cleanup

- [ ] 并行 spawn — 支持同时创建多个子智能体并行执行独立任务，而非逐个串行
- [ ] 超时控制 — 每个子智能体可设置独立超时，超时后自动终止并返回部分结果
- [ ] 资源配额 — 限制同时活跃的子智能体数量上限，防止 Token/并发爆炸
- [ ] 重试机制 — 子智能体失败后自动重试（可配置次数），或回退到父 Agent 自行处理
- [ ] 生命周期钩子 — 支持 onSpawn / onComplete / onError / onTimeout 回调，便于监控和日志

### 19. 子智能体通信与上下文 ⚠️ 当前完全隔离

- [ ] 上下文继承 — 子智能体可选择继承父 Agent 的对话历史摘要（而非从零开始）
- [ ] 结果回流 — 子智能体完成后结构化返回结果，父 Agent 可直接引用而非重新解析
- [ ] 兄弟通信 — 同一父 Agent 下的子智能体之间可互相传递中间结果
- [ ] 进度上报 — 子智能体在执行过程中定期向父 Agent 报告进度百分比和当前步骤

### 20. 子智能体编排 ⚠️ 当前无编排能力

- [ ] DAG 任务编排 — 父 Agent 定义任务依赖图（DAG），自动按拓扑顺序调度子智能体
- [ ] 结果聚合 — 多个子智能体的输出自动合并为统一结果（如多文件生成、多角度分析）
- [ ] 条件分支 — 根据前一个子智能体的输出决定后续 spawn 哪个子智能体
- [ ] 流式管道 — 子智能体 A 的输出实时流入子智能体 B 的输入，形成处理管道

### 21. 子智能体成本与可观测性 ⚠️ 当前无成本追踪

- [ ] Token 消耗统计 — 每个子智能体独立记录 Token 用量，汇总到父 Agent
- [ ] 执行日志 — 子智能体的完整执行过程可追溯（输入、工具调用、输出）
- [ ] 成本预警 — 子智能体累计 Token 超过阈值时通知父 Agent 或用户
- [ ] 性能基线 — 记录同类任务的执行耗时和 Token 消耗，为后续优化提供数据
