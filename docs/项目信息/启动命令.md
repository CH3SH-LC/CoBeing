# CoBeing 启动命令

> 最后更新：2026-04-23

## 前置要求

- **Node.js** >= 22.0.0
- **pnpm** >= 10.0.0
- **Rust** 最新稳定版（GUI 桌面应用需要，浏览器模式不需要）
- **Docker**（可选，沙箱功能需要）

## 快速启动

### 方式一：双击 start.bat（推荐）

```bash
start.bat        # 交互式选择 CLI / GUI / Both
start-gui.bat    # 直接启动 GUI（浏览器模式）
```

首次运行自动安装依赖和构建。

### 方式二：命令行

```bash
# 安装依赖
pnpm install

# CLI 模式
pnpm dev

# GUI 浏览器模式（需要两个终端）
pnpm dev                              # 终端 1：启动后端
cd gui-v2 && npm install && npm run dev  # 终端 2：启动前端

# GUI Tauri 桌面模式（需要 Rust）
cd gui-v2 && npx tauri dev
```

## 开发命令

```bash
pnpm dev          # 启动开发服务器
pnpm build        # 构建所有包
pnpm test         # 运行测试（147 个用例）
pnpm test:watch   # 测试监听模式
pnpm clean        # 清理构建产物
```

## CLI 内置命令

```
/agents    # 查看所有 Agent
/groups    # 查看所有群组
/registry  # 查看注册表
/gateway   # 查看 LLM 网关状态
/help      # 查看帮助
/quit      # 退出
```

## 配置

```bash
# 1. 复制环境变量模板
cp .env.example .env

# 2. 编辑 .env，填入 API Key
# DEEPSEEK_API_KEY=sk-xxx

# 3. （可选）修改 config/default.json 调整默认配置
```

## 桌面应用打包

```bash
# 双击 build-gui.bat 或手动执行：
cd gui-v2
npm install
npx tauri build

# 输出位置：gui-v2/src-tauri/target/release/bundle/
```

## 故障排查

| 问题 | 解决方案 |
|------|----------|
| Cannot find module | `pnpm clean && pnpm build` |
| GUI 连接失败 | 确认后端显示 "WS Server started on port 18765" |
| Agent 创建失败 | 检查 `.env` 中的 API Key 和网络连接 |
| Docker 沙箱失败 | `docker ps` 确认 Docker 正在运行 |
