# CoBeing 前端设计清单

> 最后更新：2026-05-12 | P0-P2 已完成
> 技术栈：React 19 + Tauri 2.0 + shadcn/ui + Zustand + Vite
> 组件数：~40 个 TSX 文件 (~8K LOC)

---

## 一、整体架构

```
gui-v2/
├── src-tauri/          # Tauri 2.0 Rust 后端 (桌面壳)
└── src/                # React 19 前端
    ├── components/     # UI 组件 (按功能域划分)
    ├── hooks/          # 自定义 Hooks
    ├── stores/         # Zustand 状态管理
    └── lib/            # 工具库
```

**通信方式**: React ↔ WebSocket (端口 18765) ↔ Core

## 六、设计系统

### 6.1 主题

Tokyo Night 暗色主题为基础，支持主题切换。主题配置在 `public/themes.json`。

### 6.2 颜色体系

**背景色**
| 用途 | 颜色 |
|------|------|
| 基础背景 | `#1A1B26` |
| 表面背景 | `#16161E` |
| 抬升背景 | `#1F2030` |
| 悬停背景 | `#282A3E` |
| 输入框背景 | `#14141C` |

**主题色**
| 用途 | 颜色 |
|------|------|
| Agent 蓝色 | `#7AA2F7` |
| Group 紫色 | `#BB9AF7` |
| 成功/空闲 | `#9ECE6A` |
| 警告/运行 | `#E0AF68` |
| 错误 | `#F7768E` |

**消息气泡**
| 类型 | 背景 | 强调色 |
|------|------|--------|
| 用户 | `#1C2648` | 蓝色 |
| 助手 | `#16261C` | 绿色 |
| 系统 | `#262216` | 橙色 |

### 6.3 动画

| 场景 | 效果 |
|------|------|
| 流式响应 | 脉冲圆点 alpha 呼吸动画 |
| 消息气泡 | 淡入 150ms |
| 对话框 | 缩放淡入 200ms |
| 按钮 | 点击轻微缩小 100ms |
