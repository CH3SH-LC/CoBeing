# CoBeing 用户功能清单

> 最后更新：2026-04-21 | 从用户视角描述可用功能

---

## 一、对话功能

### 1.1 与 Agent 对话
- 选择一个 Agent 开始对话
- 实时流式响应，逐字显示 AI 回复
- 支持 Markdown 格式渲染和代码高亮
- 消息自动带时间戳

### 1.2 群组聊天
- 进入群组查看多 Agent 协作讨论
- 实时观看 Agent 之间的互动
- 向群组发送消息参与讨论
- 查看 Agent 工具调用过程

### 1.3 输入方式
- 文本输入框，支持多行
- Enter 发送，Shift+Enter 换行
- 发送中自动禁用输入，防止重复

---

## 二、Agent 管理

### 2.1 创建 Agent
- 填写名称和角色
- 选择 LLM Provider 和模型
- 可选填 System Prompt 自定义行为
- 创建后自动出现在侧边栏

### 2.2 查看 Agent
- 侧边栏列表显示所有 Agent
- 每个卡片显示：名称、状态灯、角色、Provider/Model
- 状态灯颜色：绿色(空闲)、黄色(运行中)、红色(错误)

### 2.3 Agent 详情
- **配置标签页**: 修改 Provider、Model、权限、工具
- **文件标签页**: 查看 Agent 的性格特征、工作职责、经验积累等文件
- Agent 可以自我更新这些文件

### 2.4 销毁 Agent
- 从 Agent 详情面板销毁不需要的 Agent
- 同时清理相关数据

---

## 三、群组管理

### 3.1 创建群组
- 填写群组名称
- 从现有 Agent 中选择成员（多选）
- 可选填协作主题
- 创建后自动出现在群组列表

### 3.2 查看群组
- 侧边栏切换到 Groups 标签查看
- 每个卡片显示：名称、成员数、成员列表

### 3.3 群组详情
- **配置标签页**: 群组设置
- **成员标签页**: 查看/管理群组成员
- **工作空间标签页**: 查看项目文档（成员列表、项目结构、任务、进度、计划）

### 3.4 销毁群组
- 从群组详情面板销毁

---

## 四、智能管家 (Butler)

### 4.1 自动可用
- 系统启动时自动创建管家 Agent
- 拥有完全访问权限

### 4.2 自然语言管理
- 可以用自然语言让管家执行操作：
  - "帮我创建一个代码审查专家"
  - "创建一个开发团队，包括前端和后端"
  - "列出所有 Agent"

---

## 五、设置

### 5.1 Provider 管理
- 配置 9 家 LLM Provider 的 API Key：
  - Anthropic (Claude)、OpenAI (GPT)、Google Gemini
  - DeepSeek、智谱 GLM、通义千问
  - MiniMax、豆包、Grok
- API Key 通过 `.env` 文件管理，不在界面明文存储

### 5.2 Channel 管理
- 配置外部通信渠道：QQ、Discord、企业微信、飞书
- 启用/禁用特定渠道
- 将渠道绑定到群组

### 5.3 MCP 服务器
- 配置外部 MCP 工具服务器
- 支持 stdio 和 HTTP 两种连接方式

### 5.4 主题
- 暗色/亮色主题切换
- Tokyo Night 风格默认主题

### 5.5 日志
- 查看系统运行日志

### 5.6 关于
- 应用版本信息

## 八、桌面应用

### 8.1 安装包
- Windows .exe 安装包
- Windows .msi 安装包

### 8.2 启动方式
- 双击桌面图标启动
- `start.bat` 启动后端 + `start-gui.bat` 启动前端

---

## 九、数据与隐私

### 9.1 数据存储
- 所有数据存储在本地 `data/` 目录
- Agent 配置、对话历史、经验积累全部本地保存
- 不上传到任何云端

### 9.2 API Key 管理
- 通过 `.env` 文件管理 API Key
- `.env.example` 提供模板参考
- 界面不显示 API Key 明文
