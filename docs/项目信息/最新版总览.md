## 四、能力域盘点（当前实现事实）

### 1. 后端运行时（CoBeingRuntime）

- 顶层编排器：启动 Provider / 插件 / Butler / Agent / Group / MCP / WS / Channel / TODO 扫描器；`start()` / `stop()` 对称清理。
- 2026-08-11 重构后主体职责拆分到 `runtime/`：`plugin-loader.ts` / `providers.ts` / `market.ts` / `channels.ts` / `core-agents.ts` / `sandbox-helper.ts`，`runtime.ts` 保留薄转发（864 行）。
- SQLite 策略：优先真实 `better-sqlite3`（Node 24 原生绑定），Memory / Group / Observability 缺失时降级 JSON / 内存，启动不被 native 异常阻断。

### 2. Agent 体系

- **五文件体系**：`AGENTS.md`（运行/工具/协作规则）、`EXPRESSION.md`（人味表达规范，无身份设定，2026-08-05 起取代 CHARACTER；历史 Agent 兼容）、`JOB.md`（职责/方法论）、`MEMORY.md`（事件记忆）、`EXPERIENCE.md`（长期经验）、`config.json`（模型/权限/工具/沙箱/技能白名单）。
- 附加数据：`capability.json`（能力卡）、`inbox.json`（任务收件箱）、`reflection.json`（反思）、`proposals/`（成长建议）。
- Prompt 构建：静态层 → AGENTS.md → 表达层（优先 EXPRESSION，管家走 CHARACTER 兼容路径）→ JOB.md → 动态上下文；「怎么说」与「怎么做」分离。
- 会话循环：ConversationLoop + 群组工作推回（承诺即产出）、思考轮继续、工具结果 8K 截断、chat maxTokens 8192；工作目录 fail-fast（缺失即拒绝，不兜底 cwd）；LLMGateway 全局必经（队列 + RPM 限流 + 超时 + 重试 + 降级）。

### 3. Butler 管家入口

- 定位：用户第一联系人，职责收敛为对话 / 管理 Agent / 管理群组；**执行类工具已被结构性移除**（BUTLER_DEFAULT_TOOLS 不含 bash/edit-file/glob/grep，保留 read/write 供个人事务 md，运行时强制过滤 + 修复 config）。
- 文件体系：`ensureButlerDir()` 首启创建；4 人格模板（亲密朋友/专业秘书/学习陪伴/家庭助理）×（CHARACTER + JOB）；`butler_set_persona` / `butler_update_style` 切换与自定义。
- 任务转接：tracked dispatch → Global TODO + ButlerTask + Agent inbox / Group TODO；`butler_task_updated` 结构化广播 → 前端 TaskReceiptCard 回执卡片；`dispatch_task` 支持 agent/group 双目标；Host 事件桥 `host-report-event`（6 类 → `butler_escalation` 广播，前端已接线 waiting_user + 通知）。
- 多步推进流程：澄清 → 推进 → 确认点（必须停下等用户）→ 继续；Market 低打扰推荐纪律（官方且明显更优才提示 ≤1 次/会话）。

### 4. Group 群组协作

- 生命周期 + GroupContextV2 + WakeSystem（@mention 唤醒队列）+ 群组工作区（GUIDE.md + EXPERIENCE.md 自动创建）+ GroupDB / 群组记忆（SQLite，降级内存）。
- **纯 prompt 驱动协作**：HOST_JOB.md（群主 9 项职责 + 用户决策制）+ 群组上下文 6 步判断 + `group-send` 非阻塞旁路；群主不自执行（运行时移除 8 个执行工具）。
- 并发纪律：file-version CAS（read-file 附版本行、write/edit-file baseVersion 校验拒绝过期覆盖）+ GROUP_MECHANICS_NOTICE 写文件纪律；保留群组多 Agent 并发执行能力。
- 用户参与：`@用户`（@用户/@主人/@老板/@user）唤醒 + 通知 + 未读；平时协作消息不通知不计未读（低打扰）。

### 5. TODOboard（三层）

- Agent TODO / Group TODO / Global TODO 三层；Agent 级 0time / repeat / condition / stale 重唤醒触发；GlobalTodoStore 为唯一账本（ButlerTask eventLog 追加式事件日志 + agent-task-accept 原子认领）。
- Butler 5 个编排工具（add/list/update/link/continue）+ 前端 GlobalTodoPanel + Agent 对话区 TODO 横幅 + GUI「下次触发/已触发待完成」标记。

### 6. 记忆与经验

- MemoryStore：Markdown + SQLite/FTS5、冻结快照、信任评分、安全扫描；MemoryEntry ttl/provenance 归一化 + Q1/Q2/Q3 写入纪律 + 每周整合 JOB.md。
- Memory ToolAgent：经验条目提取（`entries + memoryUpdates + warnings`），MEMORY.md 修改仅作建议。
- HRR 检索 Phase 2 真实现：SHA-256 确定性相位向量（bind/unbind/bundle/similarity）。

### 7. 工具、权限与安全

- 工具系统：bash、文件读写、edit、glob、grep、web-fetch、memory、TODO、skill、group、MCP bridge 等。
- **5 级权限体系**（ReadOnly → WorkspaceReadWrite → WorkspaceAccess → BasicAccess → FullAccess）+ PermissionMode `auto` 安全分类器（reasoning-blind LLM 裁决 allow/deny/ask、fail-closed、熔断、allow 缓存）+ bash 命令动态分级 + 可选 Docker 沙箱降级路径。
- 防御工程：path-guard（数据目录段前缀拦截）、符号链接逃逸防护、提示注入检测（13EN+18CN）、PBKDF2 密钥、CSP、WS 频率/体积限制、工作区绑定防根目录。
- **预算熔断**：ConversationLoop maxTotalTokens 全链路透传 + 双重检查；不可逆工具（bash/write/edit/rm/web-fetch）emit `tool:irreversible` 审计事件。

### 8. 扩展体系：插件 / 技能 / MCP

- plugin-sdk：manifest / loader / HookBus（12 事件三语义）/ PromptLayerRegistry / UIExtensionRegistry；registry.json 驱动加载；Provider 数据插件（deepseek 默认，zhipu/qwen/minimax/volcengine/moonshot/mimo/custom 默认 disabled）。
- SkillRepository：SKILL.md 加载 + 前端技能执行真实链路（execute_skill）。
- MCP：client / manager / stdio/http transport / bridge tool；**mcp-register 附带【使用指南】**（instructions 字段接通）。
- 内置 4 个 MCP server 包：
  - `claude-code`（v0.1.0，2026-08-11）：Agent SDK 异步轮询 5 工具、working_dir fail-fast、session 延续、预算 $2/50 轮；bypassPermissions 写 jail 边界已在文档注明。
  - `browser`（2026-08-12）：Playwright chromium 9 工具（navigate/get_text/screenshot/search/click/fill/download/save_login_state/status）、登录态持久化（storageState 存 `data/mcp/browser-state.json`）、URL 仅 http/https、操作超时 30s、playwright 缺失降级。
  - `qqbot`（2026-08-12 补完）：官方 v2 access_token 鉴权（修复废弃 `Bot appId.token`）、22 工具、config.channels → QQBotChannel 接线（bindTo butler）、StdioTransport env 继承（子进程可读 .env 凭据）。
  - `office`（32 办公工具，手动配置启用）。

### 9. Market 分级机制（v1）

- 四层信任分级：official（内置）/ certified（预留）/ community（强制确认）/ local（本地聚合）。
- 依赖树透明（group → agent → skill）+ 防环 + 社区确认门禁（安装器层 + GUI 确认流双层）+ 路径穿越防护 + 幂等。
- Butler 推荐/安装工具（低打扰纪律）；WS 5 命令（market_list/get/install/uninstall/installed）；GUI 扩展页 Market Tab。
- 内置示例：官方「旅行规划」skill/agent/group 完整依赖链 + 社区「记账小助手」门禁演示。
- 边界：persona/plugin 资源未入安装链路；certified 审核流程、认证远程市场、社区版本更新机制未落地。

### 10. GUI（React 19 + Tauri 2）

- 六入口（管家/智能体/群组/仪表盘/扩展/设置），2026-08-09 起默认只露「管家 + 设置」，「⋯」菜单 + advancedNav 开关（面向普通用户的入口收敛）。
- 三层主体卡片布局 + 磨砂浮层；默认 sakura-mint 主题（樱花薄荷，糖果色层次），executive-workbench 工作台主题保留。
- 真实数据流：回执卡片状态流转、全局任务面板、技能执行、沙箱真实指标（docker stats）、通知音效（Web Audio + 系统通知）、@用户 唤醒（未读徽章）、时间线/健康 tab、唤醒队列、仪表盘。
- 个人资料：昵称/首字/Emoji/图片头像，单聊群聊真实头像（用户右、智能体左）。

### 11. 治理与质量
