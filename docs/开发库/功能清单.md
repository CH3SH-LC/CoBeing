## 维护规则

1. **新功能落地** → 在对应域新增一行并标 ✅（备注版本/日期）；同时按规则更新 `PROGRESS.md`（详细）+ `PROGRESS-LITE.md`（速查）。
2. **状态变化**（如 📌→✅、✅→🚧）→ 只改本文件状态标记，并把结果回填到 `../项目信息/当前待办.md`。
3. **移除功能** → 删除对应行，并在「已移除」备忘（`想法.md` 的决策备忘区）留痕。
4. **统计表** → 每次增删行后同步更新「总览统计」数字。
5. 内容必须与代码实际状态一致，不得有幻觉；细节以 `项目现状.md`、`当前待办.md`、`PROGRESS.md` 为准。
