# P1.1 Agent 自我进化闭环 — 设计文档

> 日期：2026-05-08 | 状态：已确认

## 概述

让 Agent 在使用中自动成长：从反馈中调整性格、积累工具策略、深化经验反思。通过扩展 experience-reflect 工具和 prompt-builder 实现。

## 设计决策

| 项目 | 方案 |
|------|------|
| 性格调整 | 扩展 experience-reflect，新增 `soul_update` 参数 → 追加 SOUL.md |
| 工具策略 | 扩展 experience-reflect，新增 `tool_usage` 参数 → 追加 TOOLS.md |
| 经验增强 | 扩展 experience-reflect，新增 `lesson` 参数 → EXPERIENCE.md |
| BOOTSTRAP 持久 | 现有行为已正确（不删除），无需改动 |
| Skill 注入 | prompt-builder 从 config.json 读取 skills 列表自动注入 |

## 改动清单

### 1. 扩展 experience-reflect 工具

`packages/core/src/tools/experience-reflect.ts`

新增 3 个可选参数：`lesson`、`soul_update`、`tool_usage`

存储规则：
- `lesson` → EXPERIENCE.md `## 教训` 段
- `soul_update` → SOUL.md 末尾 `## 自我进化` 段
- `tool_usage` → TOOLS.md `## 策略` 段（场景→工具→效果）

### 2. BOOTSTRAP Skill 列表注入

`packages/core/src/conversation/prompt-builder.ts`

在 `buildSystemPromptFromFiles()` 中 BOOTSTRAP 段之后，从 `config.json` 读取 `skills` 字段，追加"当前装载的技能"行。

### 3. AgentFiles 新增文件路径

`packages/core/src/agent/paths.ts`

确保 TOOLS.md 路径已定义（检查是否已有，无则新增）。

## 文件影响

| 操作 | 文件 | 说明 |
|------|------|------|
| Modify | `packages/core/src/tools/experience-reflect.ts` | 新增 lesson/soul_update/tool_usage 参数 |
| Modify | `packages/core/src/conversation/prompt-builder.ts` | BOOTSTRAP 后注入 Skill 列表 |
| Check | `packages/core/src/agent/paths.ts` | 确认 TOOLS.md 路径存在 |

## 构建

后端 .ts 变更，`pnpm build`。前端无影响。

## 边界情况

- **soul_update 空字符串**: 跳过不写入
- **TOOLS.md 不存在**: 首次写入时自动创建
- **config.json 无 skills 字段**: 不注入技能列表，不影响正常流程
- **多次 soul_update**: 追加模式，不覆盖已有内容
