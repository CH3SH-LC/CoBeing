Agent Swarm Kit 是一个用 TypeScript 编写的**轻量级、框架无关的多智能体系统开发库**。它提供了一套模块化的工具，让你能像一个经理那样，组织一个由多个拥有专长的AI助手组成的团队，通过自动化协作来完成复杂任务，从而将你的精力从繁琐的步骤中解放出来。

它的核心理念是构建一支专业的AI团队：
*   **Agent Swarm vs. 传统Agent**：如果说传统的单一AI助手需要你一步步指导，那么Agent Swarm则允许你发出一条指令，然后AI团队便会自行进行任务拆解、分工、沟通并最终完成整个工作流程。其核心的三大协作机制分别是：
    *   **共享任务列表**：提供一个统一的“任务板”，所有AI智能体都能在上面看到总体任务目标、子任务进度和状态，确保团队步调一致。
    *   **消息邮箱系统**：一个智能体间的通信系统，允许它们直接相互询问、回复、确认进度或共享信息，无需通过用户中转，极大地提升了协作效率。
    *   **独立上下文**：每个智能体都拥有独立的上下文记忆，互不干扰，从根本上解决了复杂任务中上下文信息过载或混淆的问题，让每个智能体都能专注于自己的工作。

### 🏗️ 架构与组件

Agent Swarm Kit采用分层架构，核心组件包括：
*   **Session**：代表一次用户与系统的对话，是整个消息流程的总入口，负责管理会话。
*   **Swarm**：智能体的集合，像一个“路由中心”，负责将用户请求或内部消息路由到合适的目标智能体。
*   **Agent**：具体的智能体执行单元，它拥有特定的角色、系统提示词，并能调用专属的工具来完成任务。
*   **工具系统**：智能体执行具体操作（如查询数据库、发送邮件、导航到其他智能体）的扩展功能。

技术实现上，它采用了**依赖注入 (DI)** 的架构，将日志、连接、存储等功能都封装成独立可替换的服务，这保证了系统的高度模块化与可测试性。同时，它使用响应式编程范式来处理异步数据流，以更好地适应实时任务。

### ⚙️ 主要特性与优势

*   **框架无关，模型中立**：它与特定的AI模型或框架解耦，可以灵活接入多种大语言模型（LLM）提供商，例如 **OpenAI、Ollama、Groq、Claude、NVIDIA NIM** 等，让你能在一个团队中集成不同模型的特长。
*   **轻量级与易用性**：相比于 LangChain 等框架，其设计更为轻量，API也更简洁，希望能让你专注于业务逻辑而非底层架构。
*   **生产就绪**：它考虑了实际生产环境的需求，提供了Redis集成以支持会话、状态和历史消息的持久化存储，确保系统在分布式环境中也能可靠运行。
*   **开发运维友好**：
    *   **集成MCP**：原生支持 **Model Context Protocol (MCP) 协议**，可以无缝接入用不同语言编写的海量外部工具。
    *   **交互式测试台**：内置了一套测试框架，可以方便地模拟和验证智能体间的交互，方便进行调试。
    *   **自动文档生成**：能自动根据你的智能体配置生成Markdown格式的文档，方便团队内部同步和知识沉淀。

### 💡 注意事项与区分

*   **注意区分相关概念**：例如，OpenAI 曾推出过一个名为 **"Swarm"** 的实验性多智能体框架（已于2025年3月关闭），二者目的相似但并非同一个项目。
*   **快速上手**：在项目中，你可以通过npm安装它：
    ```bash
    npm install agent-swarm-kit
    ```
    随后通过其暴露的接口定义智能体，为其分配角色、提示词和工具，并开启协作任务。
*   **示例代码**：以下是一个简单的分诊智能体代码片段，它可以根据用户指令，将任务导航到不同的子智能体来处理：
    ```typescript
    import { addAgent, addCompletion, addSwarm, addTool, changeAgent, execute, session, Adapter } from "agent-swarm-kit";
    // ... 定义导航工具
    const NAVIGATE_TOOL = addTool({ ... });
    // ... 定义模型和智能体
    ```

总的来说，Agent Swarm Kit是一个旨在将AI应用从“单兵作战”模式升级为“集团军协同”的实用工具。它通过提供一个灵活、可扩展的框架，让你能够高效地组织、管理和协调一支AI团队，从而构建起下一代复杂的智能自动化系统。
