AgentCiv Engine 是一个面向多智能体 AI 系统的开源引擎。它将**“团队（组织）结构”**作为软件架构中的一级设计参数，让开发者能像配置技术栈一样，自由选择或由智能体自主设计高效的组织和协作模式。

其核心任务抽象和团队结构设计是其区别于其他多智能体框架的关键。

### 🔧 核心抽象：不只是“打工人”，更是“组织行为学”实验场

AgentCiv Engine 的核心创新在于，它将任务成功完成所需的工作流，抽象为可配置的组织行为。它将“如何组织团队去工作”本身，变成了一个可探索、可优化的变量。

*   **13种开箱即用的团队结构**：让你可以像选择设计模式一样，为特定任务（如开发API、修复Bug）选择或试验不同的团队模式。

以下是其主要结构及特点：

| 团队结构 | 协作模式 | 决策机制 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **collaborative (协作型)** | 扁平、开放，所有人可见全部信息 | 角色自发涌现 | 快速原型开发、知识分享 |
| **competitive (竞争型)** | Agent独立工作，互不干涉 | 解决方案择优（赢家通吃） | 算法优化、参数寻优 |
| **meritocratic (精英型)** | 基于质量获得影响力 | 强制同行评审，声誉构建 | 高质量代码审查、关键系统设计 |
| **hierarchical (层级型)** | 领导者分配任务并负责协调 | 自上而下的命令链 | 大型项目规划、复杂系统集成 |
| **startup (初创型)** | 扁平、极简流程 | 速度快，无评审环节 | 产品快速迭代、市场验证 |
| **pair-programming (结对编程)** | 两人高耦合协作 | 角色轮换（一人写码，一人审查） | 复杂逻辑开发、知识传递 |
| **open-source (开源型)** | 分布式权威，透明 | 社区声誉和贡献驱动的维护者制度 | 需要广泛社区参与的项目 |
| **military (军事型)** | 严格命令链 | 绝对服从，无自主决策，信息“按需知晓” | 高度结构化、风险规避的任务 |
| **research-lab (研究型)** | 分头探索，后整合汇总 | 探索性，鼓励多样性 | 技术预研、创新方案设计 |
| **swarm (蜂群型)** | 无直接沟通，通过环境变化协同 | 去中心化，涌现式适应 | 环境感知、动态自适应系统 |
| **hackathon (黑客松型)** | 高度并行，广播式沟通 | 追求极限速度，快速交付 | 限时、创意性原型开发 |
| **code-review (代码审查型)** | 质量优先，流程受控 | 任意变动需至少两人复核 | 核心资产维护、发布前审核 |
| **auto (动态自适应型)** | **“皇冠上的明珠”**：智能体自主讨论、投票并实时调整团队结构 | 基于历史经验进化 | 任务复杂、需探索最佳协作模式的场景 |

### ⚙️ 工作流程：从安装到执行

#### 安装与配置

1.  通过 pip 安装引擎：
    ```bash
    pip install agentciv-engine
    ```
2.  在项目根目录运行 `agentciv setup`，它会为你配置好 Claude Code 或 Cursor 所需的 MCP 服务器，并写入团队结构的配置文件。

#### 任务执行

安装完成后，即可通过多种方式运行任务。

1.  **自然语言驱动 (推荐)**
    在 Claude Code 等AI编程助手中，直接用自然语言描述你的需求，指定团队结构：
    ```bash
    # 使用精英团队构建REST API
    "Use agentciv to build a REST API with a meritocratic team"
    # 让一对编程搭档修复这个Bug
    "Set up a pair-programming duo for this bug"
    # 让AI自己决定最佳团队结构
    "Use agentciv to refactor the authentication module –-org auto"
    ```

2.  **API模式 (供研究者和高级用户)**
    通过命令行直接调用，适合自动化或批量测试不同团队结构：
    ```bash
    # 启动4个Agent组成协作团队，执行特定任务
    agentciv solve --task "Build a REST API" --org collaborative --agents 4
    # 运行实验，对比不同团队结构在相同任务上的表现
    agentciv experiment --task "Build a CLI tool" --orgs collaborative,meritocratic,auto
    # 查看更多高级选项
    agentciv info
    ```

### 🧠 动态自组织：“皇冠上的明珠”—— Auto Mode

这是 AgentCiv Engine 最具特色的功能，能实时动态地优化团队。

*   **核心机制**：当指定 `--org auto` 后，智能体团队会周期性地进入一个 **“元节拍（meta-tick）”**。在这个阶段，任何智能体都可以提议调整9大组织维度（如权威、沟通模式、角色分配、决策机制等），并通过**投票**来决定是否采纳，从而在任务执行过程中实时重塑团队。

*   **学习能力**：Auto Mode 具备学习能力。它会保存每次运行的结果，并在未来的“auto”任务中查询历史记录，为相似的挑战找到更优解。这意味着，随着使用，这套系统的“团队组织智慧”会不断累积和进化。

### 🌏 与“CivAgent”和“AgentCivic”的关系

在相关讨论中，你可能会遇到名称相似的技术，但它们有着本质区别：

*   **AgentCiv Engine**：即本文介绍的核心，一个通用、开源的**多智能体协作引擎**。
*   **CivAgent**：这是一个特定的**研究项目**，基于有名的策略游戏“文明”的开源版本“Unciv”构建。它将大型语言模型（LLM）作为智能体接入游戏，用于研究“数字玩家”在复杂策略游戏中的行为，其定位是一个专用的“AI玩家”，而非通用协作引擎。
*   **AgentCivic**：这是一个被称为“宪法AI系统”的**应用项目**。它使用了一个由4个专业Agent组成的工作流，将洛杉矶市的311投诉数据自动处理转化为经过“公平性验证”的政策建议。其目的非常聚焦——解决特定城市问题。

### 💎 总结

AgentCiv Engine 是一个将软件工程与组织行为学、社会学实验相融合的实验性项目，为构建真正智能、能够自适应协作的AI系统提供了一种新的可能。
