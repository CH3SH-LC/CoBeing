## 火山引擎 & 豆包大模型本地接入指南

本指南用于帮助开发者通过火山方舟/火山引擎平台，在本地以标准HTTP或官方SDK的方式，接入并调用豆包大模型家族及其他云上托管的大模型服务。


### 一、概述

火山引擎是字节跳动旗下的云服务平台，其大模型服务以 **豆包大模型** 为核心，通过 **火山方舟** (Ark) 平台提供统一的模型接入与管理能力。平台支持文本生成、多模态理解、图片生成、视频生成等多种模型，并提供**在线推理**和**专属资源/保障包**等多种部署与计费模式。

API协议兼容OpenAI格式，可使用标准SDK或直接发起HTTP请求进行调用。同时，平台提供了**通用模型接口**与**代码编写优化接口**两个独立的接入端点。


### 二、核心配置与鉴权

#### 2.1 服务地址 (Base URL)

火山方舟提供API分为两类接口：面向业务数据传输**数据面 API**和用于资源管理的 **管控面 API**。

- **对话/补全 (Chat Completions)** : `https://ark.cn-beijing.volces.com/api/v3`
- **编码/代码优化 (Code Plan)** : `https://ark.cn-beijing.volces.com/api/coding/v3`
- **向量嵌入 (Embeddings)** : `https://ark.cn-beijing.volces.com/api/v3/embeddings`
- **管理类API (管控面 API)** : `https://ark.cn-beijing.volcengineapi.com/`
- **AI加速网关 (接入自部署模型)** : `https://console.volcengine.com/dcdn/aigateway/instance`

> **重要提示**：
> - 编码接口的独立性：请务必区分通用模型与代码优化模型的接入端点和模型标识，错误的端点配置可能导致调用失败或产生非预期费用。
> - AI加速网关：此网关支持接入兼容OpenAI协议的**自部署模型**。配置时需填写`BaseURL`和`API Key`。自部署模型仅支持OpenAI兼容协议方式调用。

#### 2.2 鉴权方式

API请求通过HTTP Header的`Authorization`进行鉴权。推荐使用简单易用的**API Key鉴权**。

```http
Authorization: Bearer YOUR_API_KEY
```

以curl命令的一个完整调用示例如下，可按需替换`model`字段的Model ID：

```bash
curl https://ark.cn-beijing.volces.com/api/v3/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -d '{
    "model": "doubao-seed-2-0-lite-260215",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ]
  }'
```


> ⚠️ **安全建议**：请妥善保管API Key，并在生产环境中通过环境变量或密钥管理服务进行管理，切勿将其硬编码在客户端代码或公开仓库中。火山引擎也支持通过访问密钥 (AK/SK) 进行更精细的权限管理，适用于企业级场景，此处因用户主要需求不做详细展开。


### 三、预备工作

#### 3.1 注册与登录

访问 [火山引擎控制台](https://console.volcengine.com)，注册/登录账号。

#### 3.2 创建API Key

登录控制台，进入“[火山方舟](https://console.volcengine.com/ark)”服务。在左侧导航栏的“API Key管理”中，点击“创建API Key”。创建成功后，系统会生成唯一的`API Key`，务必将其复制并妥善保存。

#### 3.3 开通模型与创建推理接入点

1.  在“火山方舟”控制台的“开通管理”中，勾选并开通你计划使用的模型服务。
2.  创建“推理接入点(Endpoint)”。在“在线推理”页面，点击“创建接入点”，填写名称，选择模型和**按Token付费**等接入模式，即可创建。
3.  等待接入点状态变为 **“健康”**后，方可正常调用。创建成功后，会生成一个接入点ID，它是一个以 **`ep-`** 开头的字符串，可以作为**model**参数的值。

### 五、本地调用方式

#### 5.1 Python SDK方式使用(推荐)

火山引擎提供了专门针对方舟平台的Python SDK，API风格与OpenAI一致，调用非常简便。

**安装依赖库：**
```bash
pip install 'volcengine-python-sdk[ark]'
```

**调用示例：**
```python
import os
from volcenginesdkarkruntime import Ark

# 初始化客户端
client = Ark(
    api_key=os.getenv("ARK_API_KEY"),    # 从环境变量获取API Key
    base_url="https://ark.cn-beijing.volces.com/api/v3",
    timeout=1800,                         # 建议30分钟以上，防止长推理超时
    max_retries=2                         # 网络波动时自动重试2次
)

# 发起对话
response = client.responses.create(
    model="doubao-seed-2-0-lite-260215",
    input=[{"role": "user", "content": "解释什么是LLM？"}]
)

print(response)
```


#### 5.2 HTTP API 方式 (requests)

若希望直接控制REST API，可以使用requests库进行调用。

```python
import requests
import json

url = "https://ark.cn-beijing.volces.com/api/v3/chat/completions"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_KEY"
}
data = {
    "model": "doubao-seed-2-0-lite-260215",
    "messages": [
        {"role": "user", "content": "中国的首都是哪里？"}
    ],
    "max_tokens": 1024,
    "temperature": 0.7
}
response = requests.post(url, headers=headers, json=data)
print(response.json())
```

如果想在请求中添加自定义header，可以通过`extra_headers`参数注入，例如通过`X-Client-Request-Id`来串联客户端和服务端日志，方便问题定位。

#### 5.3 流式与非流式

可以通过设置`"stream": true`启用流式返回，实时接收生成文本分块。SDK中只需在`create`中添加`stream=True`参数即可。


### 六、重要特性与最佳实践

#### 6.1 按 Token 计费

火山引擎的**在线推理**服务采用**按Token计费**的后付费模式，不调用不计费，适合开发测试或流量波动的业务。部分高阶模型支持更高保障的**TPM保障包**和**模型单元**计费方式。

调用完成后响应中`usage.total_tokens`字段会显示本次对话消耗的总Token数。

#### 6.2 流式调用控制

建议根据业务的响应需求调整超时参数：
```python
client = Ark(
    api_key=os.getenv("ARK_API_KEY"),
    base_url="https://ark.cn-beijing.volces.com/api/v3",
    timeout=1800,     # 推荐30分钟以上，避免长回复截断
    max_retries=2
)
```


#### 6.3 多模态理解

豆包模型具备多模态理解能力，可同时处理文本与图像输入。
```json
{
  "model": "doubao-seed-2-0-lite-260428",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "text", "text": "图中的物品是什么？" },
      { "type": "image_url", "image_url": { "url": "https://example.com/image.jpg" } }
    ]
  }]
}
```



### 七、计费与限额管理

- **计费模式**：默认为按Token后付费。价格表可通过 [方舟模型定价](https://www.volcengine.com/docs/82379/1544106) 页面的实时单价查询。
- **请求限制**：账号下各模型接口有默认限流值，例如最大RPM（每分钟请求数）30,000，TPM（每分钟Token数）5,000,000等，具体因模型而异。可通过[方舟速率限制页面](https://bigmodel.cn/usercenter/proj-mgmt/rate-limits)查看账户配额。超出额度将返回429错误，需要适当降低请求频率。
- **欠费管理**：账号欠费后1分钟内模型调用服务即被关停。请留意账户余额或设置自动续费。

### 八、常见问题排查

- **鉴权错误 (401)**：请检查`Authorization`头中`Bearer`与API Key之间是否有空格。
- **模型不存在或不可用 (400/404)**：检查**model**参数是使用的Model ID还是Endpoint ID，并确保已在控制台**开通模型**服务。
- **请求频率过高 (429)**：确认是否超过模型的并发或调用频率限制。可降低请求速率，或考虑购买TPM保障包获取更高并发。
- **连接或SSL错误**：因火山方舟服务部署在北京区(`cn-beijing`)，国内开发者可使用**全站加速网关**等服务连接，或检查本地网络是否稳定。
- **输出不完整**：尝试调高**max_tokens**值；若问题仍存在，可调高SDK的**timeout**超时设置，保障长回复顺利完成。
