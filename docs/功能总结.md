## 项目概览

MyAgents 是一个自研的多 Agent 协作框架，核心功能包括：
- 多 LLM Provider 支持
- 多通信 Channel 接入
- Agent 自治文件系统
- 事件驱动异步协作引擎
- 统一 Skill 仓库
- 原生 GUI (Rust egui)

**技术栈**: TypeScript (pnpm monorepo, 4 packages) + Rust (eframe/egui)
**代码规模**: 83 个 TS 源文件 (~12,263 行), 3 个 Rust 文件 (~1,065 行)

## 一、Agent 系统

### 1.1 Agent 基类 (`agent.ts`)
- 单个 Agent 完整生命周期管理
- 每个用户/会话独立对话循环 (`sessionLoops`)
- 状态管理: idle → running → idle
- Channel 消息处理 (`handleIncomingMessage`)
- 直接运行模式 (`run()`, 用于测试/GUI)

### 1.2 自治文件系统 (`paths.ts`)
每个 Agent 目录 (`data/agents/{id}/`) 包含:

| 文件 | 用途 | 读写方 |
|------|------|--------|
| `IDENTITY.md` | 身份：名称、角色、个性特征 | Agent 自我更新 / 管家创建时写入 |
| `SOUL.md` | 灵魂/人格描述，追加到 system prompt 最前面 | Agent 自我更新 |
| `USER.md` | 用户偏好和画像 | 用户编辑 / Agent 学习 |
| `BOOTSTRAP.md` | 启动引导，首次激活时读取后自动删除 | 管家创建时写入 |
| `AGENTS.md` | 工作空间指南：启动流程、行为准则 | 框架模板 + Agent 自我完善 |
| `EXPERIENCE.md` | 经验积累（问题-解决方案对） | 自动反思写入 |
| `MEMORY.md` | 记忆索引 | MemoryIndexer 写入 |
| `TOOLS.md` | 工具本地笔记 | Agent 维护 |
| `config.json` | 运行时配置 | 管家创建 / 用户编辑 |

### 1.3 System Prompt 构建链 (`prompt-builder.ts`)
按固定顺序从文件组装 system prompt：

```
SOUL.md → BOOTSTRAP.md → systemPrompt(role) → AGENTS.md → USER.md → EXPERIENCE.md → MEMORY.md
```

- BOOTSTRAP.md 读取后自动删除（一次性引导）
- EXPERIENCE.md 跳过短内容 (<50 字符)
- 所有内容从 .md 文件读取，不硬编码

### 1.4 ButlerAgent 管家 (`butler.ts`)
特权 Agent，管理其他 Agent 和群组，注册 20+ 工具：

**Agent 管理**: `butler-create-agent`, `butler-destroy-agent`
**群组管理**: `butler-create-group`, `butler-destroy-group`, `butler-list`, `butler-run-group`, `butler-add-to-group`
**注册表**: `butler-read-registry`, `butler-update-registry`
**任务分析**: `butler-analyze-task`
**群组通信**: `group-speak`, `talk-create`, `talk-send`, `talk-read`
**Channel 绑定**: `channel-bind`, `channel-unbind`
**工作流**: `workflow-analyze`, `workflow-plan`

创建 Agent 时自动写入:
- `config.json` (自治配置)
- 从 `config/templates/` 复制核心 .md 文件（模板变量替换）

### 1.5 AgentRegistry (`registry.ts`)
- 全局 Agent 注册/查找/注销
- 列出所有 Agent 及状态

### 1.6 SubAgentSpawner (`spawner.ts`)
- 动态创建临时子 Agent
- 继承父 Agent 的 provider 和工作目录

## 二、Skill 系统

### 2.1 SkillRepository (`repository.ts`)
统一技能仓库，从 `skills/` 目录加载 SKILL.md 格式技能：

```typescript
class SkillRepository {
  list(): SkillInfo[]           // 列出所有技能
  get(name: string): SkillDef   // 获取指定技能
  create(name, desc, prompt)    // 创建新技能
  search(keyword: string)       // 关键词搜索
  execute(name, task, params)   // 执行技能
}
```

### 2.2 统一工具 (`skill-tools.ts`)
所有 Agent 注册 3 个统一工具（不再按技能名注册独立工具）：

| 工具 | 参数 | 说明 |
|------|------|------|
| `skill-execute` | name, task, params? | 执行技能，受 config.json skills 白名单限制 |
| `skill-list` | 无 | 列出可用技能（白名单过滤后） |
| `skill-create` | name, description, prompt | 在仓库中创建新技能 |

### 2.3 技能注入
- `Agent.injectSkillRepository(repo)` — 注入仓库 + 注册 3 个工具
- 白名单过滤: `config.json` 的 `skills` 字段控制可用技能
- Runtime 创建全局 SkillRepository，注入到所有 Agent

### 2.4 现有技能
| 技能 | 目录 | 说明 |
|------|------|------|
| `code-review` | `skills/code-review/` | 系统化代码审查 (质量/安全/性能/最佳实践) |
| `project-planning` | `skills/project-planning/` | 项目规划 |
| `group-coordination` | `skills/group-coordination/` | 群组管理 (引导讨论/任务委托/主动介入/冲突处理/进度监控) |

### 2.5 旧版兼容
- `SkillLoader` — YAML/JSON 加载器（保留但不再使用）
- `SkillMdLoader` — 私有 SKILL.md 加载器（保留但不再使用）
- `OpenClawSkillLoader` — OpenClaw 风格（保留但不再使用）

## 三、群组与协作

### 3.1 GroupContextV2 (`group-context-v2.ts`)
tag-based 统一消息数组：

```typescript
interface GroupMessageV2 {
  id: string;
  tag: "main" | string;    // "main" 或 "talk-001"
  fromAgentId: string;
  content: string;
  timestamp: number;
  mentions: string[];       // 解析出的 @mention 列表
}
```

- main 消息：所有成员可见
- talk 消息：只有参与者可见
- `buildContextFor(agentId)` — 为指定 Agent 构建过滤后的上下文
- talk 消息前缀标注 `[Talk: talk-001 成员: A, B]`

### 3.2 WakeSystem (`wake-system.ts`)
事件驱动唤醒队列：

```
新消息 → 扫描 @mentions → 加入唤醒队列 → 逐个唤醒 Agent → 回复写回上下文 → 检查新 mentions
```

- 无轮次概念，完全事件驱动
- Agent 回复中的 @mention 自动触发下一轮
- 可配置唤醒间隔（默认 5 秒）
- 手动唤醒: `wakeAgent(agentId)` (用于 Screener 触发)

### 3.3 Screener (`screener.ts`)
群主双模型初筛：

- 轻量级模型，群组中每条新消息触发
- 不执行工具，只判断：是否需要唤醒主模型 / 原因 / 建议
- 输出格式固定，便于解析
- Prompt 从文件读取

### 3.4 Group (`group.ts`)
项目工作组：

- `postMessage(fromId, content)` — 发消息到 main 频道
- `createTalk(members, topic)` — 创建私有讨论
- `postToTalk(talkId, fromId, content)` — 向 talk 发消息
- `postTalkSummary(fromId, talkId, summary)` — 将 talk 结论摘要发回 main
- `wakeAgent(agentId)` — 手动唤醒 Agent
- GroupWorkspace: 5 个 Markdown 文档 (MEMBERS/STRUCTURE/TASK/PROGRESS/PLAN)

### 3.5 ChannelRouter (`router.ts`)
Channel 消息到 Group 的路由：

- **user 模式**: 消息注入 main 频道，返回最近历史
- **owner 模式**: 消息注入持久 Talk（每个 Channel 独立 Talk）
- 动态绑定/解绑
- 静态配置加载

### 3.6 群组通信工具 (`group-tools.ts`)
- `group-speak` — 在 main 频道发言 (@mention 支持)
- `talk-create` — 创建私有讨论
- `talk-send` — 在 talk 中发言
- `talk-read` — 读取 talk 历史

## 七、记忆与经验系统

### 7.1 记忆系统
- `MemoryWriter` (`memory/writer.ts`) — 每日对话原始记录写入 `memory/` 目录
- `MemoryReader` (`memory/reader.ts`) — 搜索历史对话关键词
- `MemoryIndexer` (`memory/indexer.ts`) — LLM 总结生成 `MEMORY.md` 索引

### 7.2 经验系统 (`memory/experience.ts`)
- `append(entry)` — 手动追加经验
- `reflect(task, conversation)` — LLM 自动反思提取经验
  - 传入完整对话历史（含工具调用和结果）
  - 只在有工具调用时触发（跳过闲聊）
  - 质量过滤: problem/solution < 10 字跳过
  - Prompt 从 `prompts/experience-reflect.md` 读取
- `search(keyword)` — 关键词搜索相关经验

### 7.3 事件总线 (`agent/event-bus.ts`)
- 事件类型: `group-message` / `agent-direct` / `task-complete`
- Agent 订阅总线接收自发消息
- GroupContext 集成 EventBus

## 十二、运行时 (`runtime.ts`)

MyAgentsRuntime 顶层编排器:
1. 构建多 Provider
2. 创建全局 SkillRepository
3. 创建 ButlerAgent (管家)
4. 注入 SkillRepository 到 Butler
5. 创建 GroupManager + ChannelRouter
6. `start()`:
   - 恢复已持久化的 Agent (从 config.json)
   - 注入 SkillRepository 到所有 Agent
   - 连接 ChannelRouter → Butler
   - 加载静态 Channel 绑定
   - 启动 WebSocket Server
   - 启动所有 Channel

│           ├── memory/     # Memory + Experience

│           ├── conversation/ # ConversationLoop + PromptBuilder
│           ├── workflow/   # WorkflowEngine

│           ├── butler/     # ButlerRegistry 持久化
│           ├── config/     # 配置 Schema + Loader
