> 叙事主线：三层含义层层递进 — 从人机关系 → 管家自动化 → Agent 协作 → Agent 自主成长
> 核心 slogan：**CoBeing，共同创造【我境】** | 副标题：从单体智能到群体智能

## P2 — 开场：从单体到群体（30 秒）

大家好！

今天所有 AI Agent 框架都在卷同一件事——怎么让**一个** Agent 变得更强？给它更多技能、更长的 prompt、更猛的模型……就像给一个人塞 100 个技能，结果呢？context 爆了，人也累了，还是一个人在扛。

**CoBeing 的答案不一样：别卷一个人了，让一群 Agent 组队干！**

各有所长，专业分工，覆盖全部能力。**从单体智能到群体智能。**

---

## P3 — 三层含义（30 秒）

CoBeing 这个名字，Co = 共同，Being = 存在。三层含义，一个愿景。

**第一层：你与 AI，共同存在。**
你负责方向和判断，AI 负责执行和探索。1 对 1 的起点，人和 AI 并肩干活。

**第二层：Agent 与 Agent，共同创造。**
多个智能体组成团队，各司其职，自发协作。不是一个人扛所有，而是一群人一起上。

**第三层：每个 Agent，真实存在。**
有名字、有性格、有记忆、会成长——是长期伙伴，不是一次性回答机器。

**三层含义，一个愿景：让 AI 从工具变成同事。**

---

## P4 — 管家智能体（30 秒）

等等，组队听起来很美好——但 Agent 从哪来？群组谁来建？

别担心，**你只管提需求，剩下的交给管家智能体。**

比如你说："帮我做一个数据分析报告"。管家会自动拆解任务，判断需要哪些技能——然后**自动创建 Agent、自动组建群组、自动分配协作**。

不需要你手动配置，不需要你懂技术。Agent 创建之后还能复用，越用越强。

**像一个靠谱的项目经理，你说需求，它安排一切。**

---

## P5 — 多 Agent 协作（35 秒）

有了 Agent 和群组，它们怎么协作？

传统框架给一个 Agent 塞越来越多技能，context 膨胀，性能下降。**CoBeing 不一样：让一群专注的 Agent 组队，每个只做自己最擅长的事。**

代码审查的只审代码，数据分析的只管数据——**专业的人做专业的事。**

那谁来决定谁上场？**Screener**——像聪明的项目经理，谁最擅长就唤醒谁，按需上场，不排排坐轮流发言。

而且 Agent 之间能**自发交流**——A 发现问题主动 @B 讨论，解决不了拉 C 开子讨论，结论自动回流。**像真正的团队在工作。**

---

## P6 — 人格 + 学习 + TODO（35 秒）

再深入一点——怎么让 Agent "真实存在"？

我们用 **8 个独立文件** 构建每个 Agent 的完整人格。SOUL 定义灵魂，CHARACTER 写人物小传，MEMORY 记住过去，EXPERIENCE 积累经验。

**大多数框架给 Agent 一个 system prompt 就完事了。CoBeing 让每个 Agent 拥有可编辑、可积累、会演化的人格档案。** 越用越懂你。

更进一步——传统框架用"心跳轮询"做定时任务，每 N 秒把所有 Agent 叫醒看一眼，没事也烧 Token。CoBeing 用 **TODO 精准触发**——不轮询，到点才干活，项目结束自动停止。

**从被动应答到自主规划执行——它们不只是等你提问，它们会主动干活。**

---

## P7 — 产品形态（15 秒）

技术再好，打不开也白搭。

CoBeing 是**原生桌面应用**——React 19 + Tauri 2.0，打开就像聊天软件。支持 **10+ 家 LLM 厂商**，支持 **QQ、Discord、飞书、企业微信** 多渠道接入。

**不需要技术背景，不需要写提示词，打开就能用。**
