# CoBeing 路演 PPT 设计

> 8 页幻灯片，配合 4 分钟讲稿
> 视觉关键词：明亮温暖 · 柔和渐变 · 蓝/橙/绿三色体系 · 人机触碰意象

---

## 设计规范

| 项目 | 规范 |
|------|------|
| 背景 | 米白 #FFF8F0 或极浅暖灰 #FAFAFA，局部用柔和渐变点缀 |
| 蓝色（第一层） | #4A90D9（柔蓝） |
| 橙色（第二层） | #F5A623（暖橙） |
| 绿色（第三层） | #7ED386（柔绿） |
| 正文色 | 深灰 #333333 |
| 辅助色 | 浅蓝底 #EBF3FC / 浅橙底 #FFF3E0 / 浅绿底 #E8F5E9 |
| Logo | 蓝底圆角矩形，"CO" 白色粗体 + "being" 白色细体 |
| 字体 | 标题：思源黑体 Bold 36-44pt / 正文：18-24pt |
| 风格 | 明亮背景 + 深色文字，圆角卡片，柔和阴影，温暖亲切 |
| 核心意象 | 海报中央人机双手触碰画面（首尾页背景） |
| 卡片风格 | 白色底 + 浅色边框 + 轻微投影，不要黑底 |

### Demo 截图建议

优先级排序：
1. **群组协作界面** — 多 Agent 互相对话、@mention、Screener 介入（最有冲击力）
2. **Agent 文件编辑** — 展示 SOUL/CHARACTER 等人格文件可直接 GUI 编辑
3. **管家自然语言创建 Agent** — "帮我创建一个 Python 专家" → 自动生成

> 如果做 live demo，提前准备好一个运行中的群组对话场景，避免冷启动等待。
> 如果不做 live demo，提前录一段 20 秒屏幕录制嵌入 PPT。

## 整体风格提示

| 要素 | 明亮温暖风格做法 |
|------|------------------|
| 背景 | 米白/暖灰，不用纯白也不用深色 |
| 卡片 | 白底 + 浅色底色（#EBF3FC / #FFF3E0 / #E8F5E9）+ 轻微投影 |
| 文字 | 深灰 #333，不用纯黑 |
| 强调色 | 柔和的蓝/橙/绿，不用高饱和 |
| 形状 | 圆角矩形为主，避免尖锐棱角 |
| 阴影 | 轻微柔和投影，营造层次但不沉重 |
| 图标 | 线性图标或柔和填充，避免硬边 |
| 整体感受 | 像一个温暖的协作空间，不是冷冰冰的科技展示 |
