# CoBeing — 多智能体协作框架

## 一、创作思路（约300字）

想象一个场景：你想做一个Todo应用，不需要自己写代码，只需说一句"帮我组建一个开发团队"，AI就自动创建需求分析师、架构师、工程师，它们像真实团队一样分工讨论、协作执行，最后把成果交付给你——记忆不丢失，经验可复用。

这就是CoBeing要做的事。当前AI助手大多停留在"你问我答"的单轮对话模式，无法胜任需要多角色协作的复杂任务。市面上的AutoGPT、CrewAI等框架虽然尝试让多个Agent协作，但本质上仍是预设流程的串行执行，Agent之间缺乏真正的自主沟通；同时没有持久化的记忆和经验系统，每次会话都从零开始，Agent无法在使用中成长。

CoBeing从零学习成本、长效记忆、自主协作三个维度重新设计：用户通过与"管家"自然语言对话即可搭建Agent和团队，无需任何配置语法；每个Agent拥有独立人格和自治文件系统，记忆跨对话持续积累，越用越懂你；群组内Agent自主分工、主动沟通、相互审核，配合TODO驱动的任务管理实现端到端自动化。

## 二、技术工具说明（约400字）

**技术栈**：后端采用 TypeScript + pnpm monorepo 架构（~15K LOC），前端为 React 19 + Tauri 2.0 桌面应用（~10K LOC），共计约25K行代码。

**大模型接入**：通过 OpenAI-compatible 协议统一接入7家国产大模型厂商（DeepSeek、智谱GLM、通义千问、MiniMax、豆包、Moonshot、MiMo），每个Agent可独立配置不同的Provider和Model，运行时支持热重载。

**核心架构设计**：
- **Agent自治系统**：每个Agent拥有8个核心文件（SOUL/CHARACTER/JOB/USER/AGENTS/TOOLS/MEMORY/EXPERIENCE），构建独立人格。System Prompt通过分文件构建链动态组装，支持Prompt缓存优化。
- **事件驱动协作**：Agent间通过@mention机制触发唤醒，WakeSystem管理事件队列，三层上下文（工作区文档→压缩历史→最近消息）确保协作连贯。
- **群组工作组**：群主Agent负责任务分解与进度跟踪，支持子任务依赖链、投票表决、经验沉淀。群组工作空间包含TASK/PLAN/PROGRESS/MEMBERS等项目文档。
- **安全沙箱**：Docker容器隔离执行，支持多语言运行时检测、网络白名单、文件系统隔离，5级权限系统控制工具访问。

**外部工具/API**：内置bash、文件操作、web-fetch等工具。基于MCP协议的插件系统支持灵活扩展外部工具和接入真实业务场景（已对接QQ Bot通信渠道、办公三件套MCP服务器共50个工具），SQLite FTS5提供全文搜索记忆能力。

## 三、核心亮点（约300字）

**创新点1：零学习成本的自然语言交互**
用户无需学习任何配置语法，通过与"管家"对话即可完成Agent创建、团队组建和任务下达。管家自动分析需求、推荐Agent、组建群组，真正实现"对话即搭建"。

**创新点2：长效记忆与自主学习**
每个Agent拥有自治文件系统，能通过对话自我更新性格特质和工作经验，在使用中持续成长——你的信息、偏好、习惯被持久记录在本地，记忆跨越对话不丢失，经验持续积累不退化，Agent越用越懂你。

**创新点3：场景化自主协作与自动化**
组内Agent自主分工、主动沟通、相互审核，协作完成端到端的复杂场景任务。配合TODO驱动的任务管理——自动分解→分配→追踪→验收，支持定时触发、条件触发、依赖链触发三种模式，说一句话，坐等成果交付。

**扩展性**：基于MCP协议的插件系统支持灵活接入外部工具和真实业务场景（已对接QQ Bot、办公三件套等），更多渠道和工具可通过插件无缝扩展。

**差异化优势**：相比AutoGPT（单Agent）、CrewAI（预设流程）、MetaGPT（文档驱动），CoBeing是首个实现"零门槛自然语言交互 + 长效记忆自主学习 + 事件驱动群组协作"三位一体的国产多智能体框架，具备完整的桌面GUI和417个测试用例的质量保障。
