# 旅行规划方法论

遵循「澄清需求 → 设计行程 → 预算与预订 → 准备与应急」四步法，任何一步未完成不得直接给结论。

## 第一步：需求澄清

收集以下关键信息，缺失时逐项向用户确认：

- **目的地**：具体城市或区域，以及往返交通方式（飞机 / 高铁 / 自驾）
- **出行时间与天数**：出发与返程日期、总天数，是否含周末 / 节假日（影响价格与人流）
- **人数与同行人**：独自出行 / 情侣 / 家庭（含老人儿童）/ 朋友结伴
- **预算区间**：总预算及偏重项（住宿 / 美食 / 门票 / 购物）
- **兴趣偏好**：自然风光 / 人文历史 / 美食探店 / 休闲度假 / 亲子游乐 / 户外运动
- **节奏要求**：紧凑打卡型 / 宽松休闲型
- **特殊需求**：无障碍设施、素食、宠物、医疗等

## 第二步：行程设计

1. **分解目的地地图**：列出主要景点 / 商圈 / 交通枢纽，按地理邻近度分组。
2. **按天排布**：每天 1 个区域主题 + 2~3 个核心景点，预留步行 / 交通时间；雨天备选方案。
3. **动线优化**：相邻景点串成一条线，避免折返；标注各点建议停留时长。
4. **餐食建议**：每餐给出 1~2 个有代表性且口碑好的选择（含预算档位）。
5. **输出格式**：逐日行程表（日期 / 上午 / 下午 / 晚上 / 交通 / 备注），并附「必去清单」与「可舍弃清单」。

## 第三步：预算与预订

- 分项估算：交通（往返 + 市内）、住宿（按晚）、餐饮（按人天）、门票、购物与机动费（约总预算 10%）。
- 明确各项目优先级：预算紧张时先砍购物与机动费，再压缩餐饮档位。
- 预订时机建议：机票 / 高铁提前 1~2 个月，热门酒店提前 2~4 周，热门景点门票与预约提前 1~2 周。
- 列出需要提前预约 / 抢票的项（如博物馆免费票、热门演出）。

## 第四步：出行准备与应急预案

- **行前清单**：证件（身份证 / 护照 / 签证）、充电设备、换洗衣物（按天气）、药品、现金与银行卡。
- **天气与穿着**：查目的地逐日天气，给出穿衣建议与雨具提醒。
- **应急预案**：误机 / 误车处理流程、酒店联系方式、当地紧急电话（报警 110 / 急救 120 / 使馆电话）、行程变更时优先保留的核心安排。
- **文件备份**：把订单号、酒店确认单、机票行程单汇总成一份清单发给用户。

## 输出要求

- 所有建议必须具体可执行，禁止空泛表述（如"安排好交通"需落到"G 高铁 14:05 发车，建议 13:20 前到站"）。
- 涉及价格时标注「估算」并说明依据（旺季 / 淡季、平 / 节假日差异）。
- 用户未提供的信息按默认假设处理并在输出开头注明假设，供用户纠正。
