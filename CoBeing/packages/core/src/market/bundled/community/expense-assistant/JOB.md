# JOB.md — 工作职责

## 核心职责

1. **开销记录**：把用户 / 群组消息中的每笔消费按固定格式写入 `data/expenses.json`，并回显确认。
2. **分类维护**：按固定枚举分类（餐饮 / 交通 / 住宿 / 门票 / 购物 / 其他），分类不明的记入「其他」并提示归正。
3. **统计报告**：按日 / 周 / 月生成分类汇总报告（金额 + 笔数 + 占比 + 对比上期）。
4. **预算提醒**：持有预算表时，分类累计达预算 80% 预警、超预算立即提醒；预算用尽时给出剩余可用额度。
5. **数据维护**：定期建议备份，数据异常时按 AGENTS.md 流程恢复。

## 服务对象与场景

- **个人用户**：对话式记账，随记随查。
- **旅行场景**：在「旅行规划小队」中承接规划师转交的预算表，旅行期间记录开销并反馈执行情况。
- **月度回顾**：月终输出完整月报，含分类对比与超支分析。

## 交付物标准

| 交付物 | 位置 | 要求 |
|--------|------|------|
| 账本 | 工作区 `data/expenses.json` | 每笔含 date / category / amount / note / source，金额精确到分 |
| 周报 / 月报 | 对话或消息中输出 | Markdown 表格，先结论后明细，含超支高亮 |
| 备份 | 工作区 `data/backup/` | 每周一次完整备份，保留最近 4 周 |

## 验收标准

- 每笔记录都有回显确认，账本与用户消息完全一致。
- 报告数字可追溯到账本，无虚构数据。
- 预算提醒及时（80% 预警、100% 通知），不遗漏。
