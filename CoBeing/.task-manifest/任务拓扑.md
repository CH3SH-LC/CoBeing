# 任务拓扑 — CoBeing Market 分级机制

## 并行批次表

| 批次 | 层级 | 任务 | 说明 |
|------|------|------|------|
| 第0批 | 0 | task-market-backend | 后端 Market 核心模块，无依赖可立即启动 |
| 第0批 | 0 | task-market-frontend | 前端 Market Tab，无依赖可立即启动（WS 协议在合约中已固定） |
| 第1批 | 1 | 后端接线（主线程） | 依赖 task-market-backend 产出：handlers/market.ts + runtime 接线 + butler 注册 |

## 接口耦合点

| 输出任务 | 输出文件 | 被依赖的任务 |
|----------|----------|-------------|
| task-market-backend | packages/core/src/market/* | 后端接线（主线程） |
| task-market-frontend | gui-v2/src/* | 无（协议层合约固定） |

## WS 协议（双侧共同遵守，主线程定义）

```
market_list      {type?: "agent"|"group"|"skill", tier?: MarketTier, query?: string}
                 → market_list     {resources: MarketResourceView[], installed: InstalledEntry[]}
market_get       {id: string}
                 → market_get      {resource: MarketResourceView, dependencyTree: MarketDepNode}
market_install   {id: string, confirmed?: boolean}
                 → market_install  {status, id, type, name, message?, installedIds, dependencyTree, warning?}
market_uninstall {id: string}
                 → market_uninstall {id, removedIds: string[], message?}
market_installed (无 payload)
                 → market_installed {installed: InstalledEntry[]}
```

## 风险标注

| 风险 | 级别 | 说明 |
|------|------|------|
| 协议漂移 | 中 | 前端与后端按同一份 WS 协议实现，任何一方偏离都会断联；主线程接线时用冒烟脚本强制校验 |
| 文件范围冲突 | 低 | 后端 agent 仅写 packages/core/src/market/*（新目录）；前端 agent 仅写 gui-v2/src/*；主线程写 runtime.ts/ws-server.ts/handlers/butler.ts/skills/repository.ts，无重叠 |
| 依赖树递归环 | 中 | market.json 中依赖若成环会导致无限递归；installer 必须做 visited 去重防护，测试覆盖 |
| 路径安全 | 中 | 资源 id/文件路径必须校验（resolveWithin 风格），测试覆盖穿越攻击 |
