# CoBeing 2.0 使用指南

> 适用版本：2.0.3（桌面 Windows + Android 手机端）

## 一、安装

### Windows 桌面版

1. 从 GitHub Release 下载 `CoBeing v2_2.0.3_x64-setup.exe`
2. 双击安装（当前用户模式，无需管理员）
3. 安装后从开始菜单/桌面启动「CoBeing v2」

> 桌面版已内置 Node.js 运行时与完整内核，目标机器**无需安装 Node.js 或任何其他依赖**。

### Android 手机端

1. 从 GitHub Release 下载 `CoBeing-mobile-v2.0.3-debug.apk`
2. 手机开启「允许安装未知来源应用」后安装
3. APK 为调试签名，主要用于功能体验与验证

## 二、配置模型（DeepSeek API Key）

**推荐方式：应用内「设置 → 模型」配置（支持多来源）**

1. 打开桌面端 → 顶栏「设置」→ 左侧「模型」
2. 点击「+ 添加来源」，填写：来源名称（如「DeepSeek 官方」）、API Key（必填，用于真实工作）、Base URL（默认 `https://api.deepseek.com`，留空即默认）、模型（下拉选择）
3. 点「保存来源」——第一个来源自动设为「当前使用」；可继续添加多个来源（全部保存）
4. 想切换时点目标来源的「设为当前」→ **重启应用**生效（内核启动时读取当前使用来源）

**可选模型（DeepSeek V4 系列）**：

| 模型 | 说明 |
|---|---|
| `deepseek-v4-flash` | 默认模型，快速通用 |
| `deepseek-v4-pro` | 更强推理 |
| `deepseek-v4-flash-vision-exp` | 视觉（实验） |

未配置任何来源时内核以 mock 模式运行（界面可体验，但智能体不真实工作）。

| 方式 | 操作 |
|---|---|
| Windows 桌面（推荐） | 应用内「设置 → 模型」→ 添加来源 → 保存 → 设为当前 → 重启应用 |
| Windows 桌面（备选） | 「系统设置 → 高级系统设置 → 环境变量」→ 新建用户变量 `DEEPSEEK_API_KEY` = 你的 Key → 重启 CoBeing（文件配置优先于环境变量） |
| 手机端连接 | 模型配置在电脑内核侧（手机只是远程客户端，连上即用电脑配置的模型） |

获取 Key：https://platform.deepseek.com/（API Keys 页面创建）。

> 应用内配置落盘在数据目录 `model-config.json`（`%APPDATA%\com.cobeing.v2\` 下）；首次启动后内核在该目录创建数据（名录/群组空间/经验档案/会话记录）。

## 三、界面速览

桌面端四个视图：

| 视图 | 作用 |
|---|---|
| **主对话** | 与管家但丁对话；新对话窗口；确认卡片；上下文进度 |
| **群组** | 群组列表、群内对话、mention 唤醒、任务说明、成员忙碌标记、任务摘要、归档 |
| **智能体** | 名录管理、创建向导（需批准）、销毁确认、经验档案（记忆面板+检索） |
| **设置** | 分栏布局：左侧条目（模型/检查更新/关于）+ 右侧内容；模型 = 多来源管理（添加/编辑/删除/设为当前，DeepSeek V4 系列）；检查更新 = 点击左侧条目即检查 GitHub 自动更新；关于 = 版本信息 |

手机端六个页面：对话 / 群组 / 智能体 / 控制台（远程控制面板）/ 文件 / 设置。

## 四、典型使用流程

### 1. 创建智能体

「智能体」页 → 填写名字（英文）与角色（中文职责）→ 提交创建请求 → 在待批准队列点「批准」。

示例：
- `game-dev`：游戏开发工程师：HTML/CSS/JS 网页游戏开发
- `writer`：写作者：文件撰写与代码编辑

> 智能体没有独立人格，是"组织形式"：同名智能体在不同群组是独立上下文，人格记忆共享、上下文不共享。

### 2. 创建群组并下发任务

「群组」页 → 新建（群组名 + 选择工作智能体成员，user 与 butler 自动包含）→ 进入群组 → 填写**任务说明**并发言。

```text
任务说明：写一个 hello.txt，内容为 Hello CoBeing
发言内容：请写一个 hello.txt 文件并验证内容
```

**唤醒规则（重要）**：
- 不选 @ 成员 → 发言将唤醒**全部**工作智能体（默认 @all）
- 指名 @成员 → 只唤醒对应智能体
- 忙碌的智能体会排队：完成当前工作后再处理下一次唤醒

### 3. 群组工作与状态

- 每个成员显示 ⏳ 忙碌标记；顶部状态条显示**当前任务摘要**与最近活动
- 智能体真实工作：工具调用（写文件/执行命令）的产物落在群组空间（`data/group/<群组名>/`），成员间通过落盘共享
- 进展汇报会发布到群里，**任务未完成时回合自动继续**；只有确认完成才输出最终汇报
- 发言经【诚实】审查：声称"已完成"必须有真实工具证据；"只说不做"的发言会被拦截并引导继续工作

### 4. 验收与归档

任务完成后在群里确认 → 「归档群组」→ 成员经验自动沉淀（下次同类任务可复用），历史记录保留，群组进入死亡状态（只读）。

## 五、手机端连接

1. 电脑双击 `start-remote.bat`，选择：
   - **1 局域网**：手机与电脑同一 WiFi，直接连接
   - **2 外网隧道**：cloudflared 临时隧道，异地可用（需要网络可达 cloudflared）
2. 屏幕底部高亮显示连接信息（地址 + Token），同时写入 `data/remote.info.txt`
3. 手机打开 CoBeing → 设置 → 新建连接：填入 `ws://电脑IP:端口`（或隧道 wss 地址）+ Token
4. 连接成功后：对话 / 群组实时同步 / 智能体记忆 / 远程控制（截屏、媒体键、电源、剪贴板、文件浏览下载上传）

> 外网隧道需要 cloudflared（脚本自动下载到 `tools/`）。国内网络如遇 DNS 污染，按 `CoBeing-v2/docs/v2-手机端与远程互联方案-v1.md` 处置（DoH 223.5.5.5）。

## 六、检查更新（2026-08-25 新增）

CoBeing 从 GitHub Release（https://github.com/CH3SH-LC/CoBeing/releases）获取新版本，**电脑端与手机端均可应用内检查、下载并安装**：

- **电脑端**：顶部导航栏点击「⬇ 更新」→ 自动检查 GitHub 最新正式版 → 发现新版本时显示版本号与更新内容 → 点击「下载并安装」（显示下载进度）→「启动安装程序」按安装向导完成升级，安装完成后重启应用。
- **手机端**：设置 → 检查更新 → 发现新版本时点击「下载并安装」→ 自动下载 APK 并唤起系统安装界面；若未弹出安装界面，请在系统设置中允许「CoBeing 安装未知应用」后重试。
- 仅正式版（非 pre-release）会被提示；资产命名固定为 `CoBeing.v2_<版本>_x64-setup.exe`（电脑）与 `CoBeing-mobile-<版本>-debug.apk`（手机）。

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 启动后智能体不回复 | 检查是否已配置 `DEEPSEEK_API_KEY`（mock 模式不真实工作）；检查内核状态灯 |
| 群组内发言没人响应 | 确认发言已发出（实时同步）；未选 @ 时默认唤醒全部工作智能体；检查成员忙碌状态 |
| 任务做了几轮就停了 | 查看群组内是否有【诚实审查未通过】反馈——发言声称完成但无工具证据会被拦截；真实调用工具后即可正常汇报 |
| 手机连不上 | 确认电脑防火墙放行端口（start-remote.bat LAN 模式自动处理）；确认地址/Token 与 `remote.info.txt` 一致 |
| 如何换 API Key | 修改系统环境变量后**完全退出并重新启动** CoBeing |
| 数据在哪 | 桌面：`%APPDATA%\com.cobeing.v2\`；开发模式：`CoBeing-v2/data/` |

## 八、数据与隐私

- 所有数据**本地存储**（名录/群组空间/经验档案/事件日志均为本地文件），不上传
- 仅模型调用（DeepSeek API）会发送对话内容到官方 API
- 归档群组工作区隔离保留；销毁智能体 = 清除人格经验 + 注销名录（历史记录保留）
